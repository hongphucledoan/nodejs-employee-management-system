🔧 NPM SCRIPTS:

Frontend:
- npm run dev               # Chạy Vite dev server (port 5173)
- npm run build             # Build production
- npm run preview           # Preview build

Backend:
- npm run server            # Chạy Express server (port 3001)
- npm run server:dev        # Chạy với auto-reload

Database:
- npm run seed              # Migrate mock data vào MongoDB
- npm run prisma:studio     # Mở Prisma Studio GUI (port 5555)
- npm run prisma:generate   # Generate Prisma client

🎯 CÁCH CHẠY PROJECT:

1. Khởi tạo MongoDB:
   - Tải từ: https://www.mongodb.com/try/download/community
   - Hoặc dùng MongoDB Atlas (Cloud): https://www.mongodb.com/cloud/atlas

2. Cấu hình .env:
   - Sao chép .env.example hoặc dùng DATABASE_URL sẵn có
   - Nếu dùng local: DATABASE_URL="mongodb://localhost:27017/employee_management"

3. Migrate dữ liệu:
   npm run seed

4. Chạy Backend (Terminal 1):
   npm run server:dev

5. Chạy Frontend (Terminal 2):
   npm run dev

6. Mở trình duyệt:
   http://localhost:5173

💡 TIPS:

- Dùng Prisma Studio để quản lý database GUI:
  npm run prisma:studio

- Xem API trong browser:
  http://localhost:3001/api/employees

- Kiểm tra server health:
  http://localhost:3001/health

📝 TIẾP THEO - CÁCH DÙNG API TRONG COMPONENT:

Thay vì dùng Dataset, giờ dùng hooks:

```typescript
import { useEmployees } from '../hooks/useAPI';

function MyComponent() {
  const { employees, loading, error, refresh } = useEmployees();
  
  if (loading) return <div>Đang tải...</div>;
  if (error) return <div>Lỗi: {error}</div>;
  
  return (
    <div>
      {employees.map(emp => (
        <div key={emp.id}>{emp.name}</div>
      ))}
    </div>
  );
}
```
